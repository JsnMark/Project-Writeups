# Project Writeups

A collection of writeups documenting projects whose source can't be made public.

Some of the work here comes from academic or other settings where publishing the code would violate an integrity policy. Rather than leave those projects invisible, this repo captures the design decisions, tradeoffs, things that broke, and what I learned fixing them. Think of each entry as a blog post or engineering writeup rather than a code drop.

## What you'll find here

Each writeup aims to cover:

- **The problem** - what the project set out to do and the constraints around it
- **The approach** - the architecture and the key design decisions, and why I chose them over the alternatives
- **The hard parts** - what turned out to be genuinely difficult, and how I worked through it
- **Results** - what the finished thing actually does, with benchmarks or measurements where they're meaningful
- **Lessons** - what I'd do differently, and what I took away for next time

Where it helps, I include diagrams, sanitized snippets, or illustrative pseudocode — enough to make the reasoning concrete without reproducing anything that shouldn't be shared.
