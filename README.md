# Project Writeups

This is a collection of writeups documenting projects whose source code isn't made public. Rather than leave those projects invisible, this repo captures the design decisions, tradeoffs, things that broke, and what I learned fixing them. Think of each entry as a blog post or engineering writeup rather than a code drop.

## What you'll find here

Each writeup aims to cover:

- **The problem** - What the project set out to do and the constraints around it
- **The approach** - The architecture and the key design decisions, and why I chose them over the alternatives
- **The hard parts** - What turned out to be difficult, and how I worked through it
- **Results** - What the finished thing actually does, with benchmarks or measurements where they're meaningful
- **Lessons** - What I'd do differently, and what I took away for next time

Where it helps, I'll try to include diagrams, sanitized snippets, or illustrative pseudocode.
